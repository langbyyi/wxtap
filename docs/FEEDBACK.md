# 交流反馈

> 应用内「交流反馈」页读取的就是本文档：它在源仓库维护（`docs/FEEDBACK.md`），
> 由 release 工作流随 `latest.json` 一起原样提交到默认分支，再被应用拉取渲染。

## 反馈渠道

- 问题反馈：提交 [Issue](https://github.com/langbyyi/wxtap/issues)，
  应用内「交流反馈」页的「提交 Issue」按钮直达同一地址。
  提交时请附上：微信完整版本号与芯片架构、「状态」页的版本支持状态、
  当日 `logs/wxtap-<日期>.log`（对外前先审阅脱敏）、复现步骤。
- 交流群：待补充。

## 更新说明

各版本更新内容见
[Releases](https://github.com/langbyyi/wxtap/releases) 页；
应用内「设置」页的版本检查读取的 `latest.json`，其 `notes` 字段即当次发布说明。
